# 🏦 Sistema de Conta Bancária (Java)

Aplicação de console desenvolvida em Java aplicando os fundamentos de Programação Orientada a Objetos (POO). Simula operações básicas de uma conta bancária com validação de entrada de dados e menu interativo.

## 💡 Funcionalidades

- Depósito
- Saque (com validação de saldo)
- Consulta de saldo
- Menu interativo via console
- Validação de entradas do usuário

## 🛠️ Tecnologias

- Java
- Programação Orientada a Objetos (classes, encapsulamento, métodos)
- `Scanner` para entrada de dados

## 📚 Conceitos aplicados

- Classes e objetos
- Encapsulamento (atributos privados + getters/setters)
- Validação de entrada de dados
- Estruturas condicionais e de repetição
- Menu orientado a operações (switch/case)
